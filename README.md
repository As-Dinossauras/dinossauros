## 📌 Sobre o Projeto

O **Catálogo dos 10 Dinossauros Mais Famosos** é uma plataforma educacional desenvolvida para oferecer uma navegação dinâmica e visualmente rica sobre os répteis pré-históricos mais populares que já habitaram a Terra. 

Cada perfil inclui um card interativo com dados detalhados, reconstituição visual em alta definição, linha do tempo geológica e curiosidades paleontológicas.

## 🖥️ Funcionalidades da Aplicação

* **Galeria Interativa:** Exibição de cards com efeito hover e dados rápidos de cada dinossauro.
* **Filtro por Dieta:** Organização instantânea por Carnívoros, Herbívoros ou Onívoros.
* **Modal de Detalhes:** Clique em qualquer item para abrir a ficha completa com peso, altura, habitat e descobertas fósseis.
* **Design Responsivo:** Layout adaptado para dispositivos móveis, tablets e desktops.
